## 我在做什么

我做的东西基本是同一件事的不同切面：**把模糊的诉求，变成可以判断对错的具体指标。**

- 「这张图能不能发小红书」不是审美问题，是宽度差 56px 的问题。
- 「这个效果是怎么做出来的」不是灵感问题，是光线、镜头、色温的问题。
- 「今天额度用得顺不顺」不该翻四页数据，该是一条灯带的长度。

所以这些项目大多长这样：零依赖、只解决一件事、结论确定、不联网也能跑。

## 主要项目

### [Prompt Forge · 提示词锻造炉](https://github.com/Stephen-pc/prompt-forge)

看到别人的 AI 作品想做同款，却拿不到提示词？**按维度拆，别按整体猜。**

把「很酷」「高级感」这类对人是信息、对模型是噪声的词，换成光线、材质、镜头、焦段、色温这些能被画出来的物理事实。覆盖图像 / 视频 / 文案 / 网页代码 / 音乐五个品类，提供网页版和 DeepSeek Harness 插件两种用法。

`JavaScript` · MIT · [**在线试用 →**](https://stephen-pc.github.io/prompt-forge/)

### [publish-size-check](https://github.com/Stephen-pc/publish-size-check)

AI 出图的默认尺寸，基本都过不了主流平台，而平台只会说「图片不符合要求」。

这个工具对照目标平台的几何规格，告诉你**能不能发、是哪一项过不了、能不能救**。纯标准库零依赖，原件只读。还能抓出「dpi 字段达标但实际印不出来」那一类——多数工具只比 dpi 数值，会直接放行。

`Python` · MIT

### [dsh-usage-display](https://github.com/Stephen-pc/dsh-usage-display)

把 DeepSeek Harness 的缓存命中率、token 用量、花费折成一份 JSON，然后让任何设备去读——灯带、点阵屏、墨水屏、手表、网页。

按注意力成本分四档：余光级、一瞥级、阅读级、分析级。**手腕只负责告警，桌面才负责看清。** 换终端不用改服务端。

`Python` · MIT
